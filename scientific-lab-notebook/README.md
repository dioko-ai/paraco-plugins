# Scientific Lab Notebook

See the [collection guide](https://github.com/dioko-ai/paraco-plugins#readme) for workflows, data limits and configuration.

## Install

```sh
paraco marketplace install scientific-lab-notebook --version 0.1.0 --output ./scientific-lab-notebook
```

Use a Paraco build whose catalog includes this release.

## Run

```sh
paraco run ./scientific-lab-notebook
```

Requested capabilities: `storage`. No records are seeded. Assets are included locally.
