# JSON / YAML Workbench

See the [collection guide](https://github.com/dioko-ai/paraco-plugins#readme) for workflows, data limits and configuration.

## Install

```sh
paraco marketplace install json-yaml-workbench --version 0.1.0 --output ./json-yaml-workbench
```

Use a Paraco build whose catalog includes this release.

## Run

```sh
paraco run ./json-yaml-workbench
```

Requested capabilities: none. No records are seeded. Assets are included locally.
